# SIH Provenance Vault

This repository is the canonical provenance vault for **SendIdeasHome (SIH)** and the broader **IFAM — Ideas For All Mankind** ecosystem.

It exists to preserve:

- Origin narratives (the “why”)
- Concept genesis documents (the “how it began”)
- Canonical chapters and long-form story artifacts
- Proof-of-remembrance records (hashes, timestamps, CIDs when used)

## Philosophy (Plain Language)

We prioritize the **remembrance of the originator’s contribution to mankind** over worldly compensation, while keeping attribution clear, permanent, and accessible.

This vault reflects a return to humanity’s original culture of innovation:
shared for the good of all, yet remembered forever.

## Structure

- `Provenance/` — Core vault folder  
- `Provenance/Chapters/` — Canonical narrative chapters  
- `Provenance/Origin_Narratives/` — Foundational origin stories  
- `Provenance/Concept_Genesis/` — Genesis of key concepts (BlockyRight, Own a Word, etc.)  
- `Provenance/Proof_of_Remembrance/` — Future proofs & timestamps  
- `Provenance/Templates/` — Standard provenance templates
